** Theming

sudo apt install lxappearance gnome-themes-extra


```from gemini
Install LXAppearance: This is the standard "Swiss Army knife" for theming in i3.

    sudo apt install lxappearance gnome-themes-extra

Apply a Unified Theme:

    Open lxappearance from your terminal.
    Select Adwaita (the default GNOME theme) or Adwaita-dark.
    Click Apply. This will write the necessary settings to ~/.config/gtk-3.0/settings.ini and ~/.gtkrc-2.0, covering almost all your apps.
```
